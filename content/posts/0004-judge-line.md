Phigros 的界面几乎只有黑白两色，却能一眼认出来。原因不在配色，在几个反复出现的零件。

## 判定线

游戏里那条会旋转、会跳动的白线，本质是一条 2px 的直线加一个沿它移动的 note。

搬到网页上，它变成页头的分隔线：一条渐隐的横线，线上一个青色菱形在缓慢漂移。

![判定线结构示意](/img/judge-line.svg)

拆开就是三段：

```css
.judge-line { height: 2px; background: linear-gradient(90deg, #fff 38%, rgba(255,255,255,.1)); }
.judge-bar  { width: 2px; height: 34px; background: #fff; }   /* 竖杆 */
.judge-note { width: 11px; height: 11px; background: var(--data); transform: rotate(45deg); }
```

## 菱形

音符是菱形，所以菱形成了这个视觉体系里的「可交互」标记。列表项前的点、按钮的指示器、目录的当前项，全用同一个形状：

```css
.diamond { width: 8px; height: 8px; background: var(--data); transform: rotate(45deg); }
```

不画 SVG，不用图标字体。一个旋转 45 度的方块，任何地方都能复制。

## 斜切

零圆角，切角一律走 45 度。面板、按钮、回顶控件都用同一条 `clip-path`：

```css
clip-path: polygon(0 0, 100% 0, 100% calc(100% - 12px), calc(100% - 12px) 100%, 0 100%);
```

切右下角，读起来像一块被削掉一角的金属板。

## 大字距

标题用窄体大写，字距拉到 `0.22em`。同样字号下，拉字距比加粗更像游戏 HUD。

| 做法 | 观感 |
|---|---|
| 加粗 | 厚重，像海报 |
| 加大字号 | 抢空间 |
| 拉字距 + 大写 | 冷静，像仪表盘 |

## 抄与不抄

抄的是零件和方法，不是外观。判定线换成横着的进度条，菱形换成状态灯，斜切换成切角卡片——骨架留着，皮是自己的。

> 参考设计语言不是抄界面，是抄它「用几个基本形解决所有问题」的思路。
